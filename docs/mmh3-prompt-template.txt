# MiniMax H3 Base Prompt Output Skeleton

This file intentionally mirrors the current official MiniMax H3 base-mode output contract.
Use `docs/mmh3-prompt-guidelines.md` for WebCap-specific authoring guidance.

For T2VA:

```text
integrated_multimodal_description: [Shot 1] ...

overall_soundscape: ...

non_diegetic_music: ...
```

For I2VA, prepend exactly:

```text
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
```

Then one blank line and the three base fields.

For FL2VA, prepend the official first/last alignment line:

```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.
```

Then one blank line and the three base fields.

For L2VA, prepend the official last-frame alignment line:

```text
How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.
```

Then one blank line and the three base fields.

Notes:

- `[Shot 1]` has no timestamp.
- Later shots use strictly increasing cut times inside the requested duration.
- `S.SS` is the effective duration formatted to exactly two decimal places.
- Ref2VA does **not** use this three-field base skeleton; follow the official six-section reference-mode structure documented in `docs/mmh3-prompt-guidelines.md`.
