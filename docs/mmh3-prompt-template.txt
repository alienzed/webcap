# MiniMax H3 Base Prompt Syntax Example

This file is a **reference example only**.

It mirrors MiniMax's documented base prompt syntax so it is easy to inspect when testing H3 behavior. Storyboard does **not** require Director to emit this exact structure, and WebCap does not rewrite ordinary prompts into it.

A documented T2VA-style example is:

```text
integrated_multimodal_description: [Shot 1] ...

overall_soundscape: ...

non_diegetic_music: ...
```

For exact first/last-frame modes, MiniMax also documents reference-alignment statements. WebCap may add those narrow mechanical alignment lines because they are derived from declared reference roles.

Examples:

I2VA-style first-frame alignment:

```text
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
```

FL2VA first/last alignment:

```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.
```

L2VA-style last-frame alignment:

```text
How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.
```

Notes:

- These examples are **not** Storyboard's required creative prompt contract.
- Director may use ordinary audiovisual prose when that works better.
- WebCap should store and send Director-authored prompt text unchanged.
- `[Shot 1]`, later shot timestamps, and the three documented field labels are conventions, not mandatory WebCap formatting rules.
- `S.SS` represents the effective clip duration in the mechanical alignment syntax.
- Ref2VA uses a separate task family and is outside the current Storyboard runtime.
