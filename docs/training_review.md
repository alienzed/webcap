# Training Review

Training Review is the normal launch surface for a model and visible set. It
uses the set's Normal TOMLs as the durable configuration and stores the
small, structured part of training intent in `.webcap_state.json` under
`trainingPlan`.

The review computes exact membership from visible media, captions, and enabled
bucket ladders. It shows target steps, repeat/epoch estimates, exclusions, and
the exact filenames assigned to each bucket before queueing. Exclusions are
warnings when trainable media remains; invalid configuration, unavailable
captions, incompatible initialization, or no trainable items are blockers.

Only targeted settings are edited in the durable TOML: optimizer LR, adapter
rank, optional dropout, and `force_constant_lr`. Unknown settings, formatting,
and comments remain in place. Dataset TOMLs generated by Review are marked as
such. A simple hand edit can be imported as bucket choices; a custom stanza is
left untouched and treated as Custom dataset until **Reset buckets**.

Every managed or manual reviewed launch rebuilds an opaque review fingerprint
immediately before allocating an action. The captured action contains the
reviewed subset, effective TOMLs, `training_plan.json`, exclusions, estimates,
and starting-point lineage, so changing media or TOMLs after review cannot
silently alter the queued run.

Fine-tuning from a saved LoRA is a fresh run. Review only discovers compatible
`epochN` exports recorded by actions for the current set, copies the chosen
directory to `input/initializer/`, and writes that captured directory (not the
weight filename) to `[adapter].init_from_existing` in the target effective
TOML. Checkpoint Resume remains a separate continuation workflow.
