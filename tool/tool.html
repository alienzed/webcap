                                How Test Generations works
                                
Each run freezes the selected model, prompt, generation settings, and seed across the Base render and every staged LoRA so the results are directly comparable.

                                
Prompt, model-specific settings, and candidate selection are remembered separately for each model. The seed is shared within a batch, then randomized for the next batch.

                                
The supplied ComfyUI workflow defines inference. WebCap only applies the approved Test bindings, launches it, and stores the completed media in the session.
